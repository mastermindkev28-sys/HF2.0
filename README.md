# HIGGS Studio

A private, self-hosted AI video studio. Text-to-video, image-to-video and video-to-video with open-weight
models (Wan 2.2, LTX-Video) running on ComfyUI, either on your own computer or on a free Kaggle GPU.
No subscriptions, no credits, no paid APIs.

**→ [Setup and launch guide](docs/SETUP.md)**

```
Browser UI (Next.js, static)  ──►  FastAPI studio backend (your computer)  ──►  ComfyUI backend(s)
  Create / Models / Library          job queue · SQLite · local files           local CPU/GPU, Kaggle T4,
  Characters / Assets / Settings     FFmpeg tools · engine adapters             or any GPU box (by URL)
```

| Path | What |
|---|---|
| `frontend/` | Next.js + Tailwind interface (pre-built into `frontend/out`) |
| `backend/app/engines/` | Model adapters: files to download, real capabilities, ComfyUI workflow builders |
| `backend/app/comfy.py` | ComfyUI API client (submit, websocket progress, history, download, upload) |
| `backend/app/jobs.py` | Background queue: generation, extend, stitch, upscale, interpolation |
| `custom_nodes/higgs_bridge/` | ComfyUI add-on: model download/remove, hardware stats, access token |
| `kaggle/` | Free-GPU notebook (generated by `build_notebook.py`) |
| `scripts/` | `install.sh`, `start.sh`, hardware detection |

Adding an engine: subclass `Engine` in `backend/app/engines/`, list its weight files and modes, implement
`build()` to return a ComfyUI API workflow, and register it in `engines/__init__.py`.

Tests: `cd backend && .venv/bin/python -m pytest -q` (pipeline tests use a ComfyUI test double; real
generation results are logged in [docs/TESTING.md](docs/TESTING.md)).
